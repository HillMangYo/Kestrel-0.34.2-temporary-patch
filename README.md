# Kestrel Compatibility Fix

This is a temporary fix that makes the FQ-106 Kestrel mod compatible with Nuclear Option 0.34.

It replaces the Kestrel's outdated interface with current game interface parts to prevent the crash when entering the aircraft.

## Install

Extract the release ZIP into the Nuclear Option game folder.

Requires BepInEx, Blueprinter, and the FQ-106 Kestrel mod.

Original FQ-106 Kestrel mod by [nikkorap](https://github.com/nikkorap/NOKestrel). This compatibility fix is unofficial.
